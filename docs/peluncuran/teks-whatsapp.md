# Teks ajakan WhatsApp — JukirHub

Diperbarui 30 Sept 2026. Format WhatsApp: `*tebal*`, `_miring_`. Salin apa adanya, ganti bagian `[kurung siku]`.
Kirim `qr-jukirhub.png` bersama pesan pertama.

**Prinsip (AGENTS.md 1.1):** tenang dan netral. Indikasi pungli **bukan tuduhan**; jangan menyebut tempat atau jukir
tertentu di grup, jangan mengajak berdebat atau memotret jukir. JukirHub bukan layanan pemerintah.

---

## 1. Grup warga / kompleks / kantor

```
Halo semua 👋

Ada aplikasi gratis untuk berbagi info *juru parkir di sekitar kita*: jukirnya membantu atau tidak, biasanya bayar
berapa, dapat karcis atau tidak. Namanya *JukirHub*.

👉 https://jukirhub.site/peta

Cara pakai:
1. Buka tautan, izinkan lokasi
2. Ketuk tempat Anda parkir di peta (atau ketik namanya)
3. Jawab singkat lalu kirim, kurang dari 30 detik

Tempat yang belum ada di peta? Tekan *Laporkan di lokasi saya*.
Tidak ada jukir? Pilih *Tidak ada jukir*, supaya warga lain tahu parkir di situ gratis.

Tanpa akun, tanpa nama. Laporan hanya bisa dikirim dari lokasi parkir.
```

## 2. Grup driver ojol / kurir

```
Rekan-rekan driver 🛵

Tiap hari kita parkir di depan toko, minimarket, warung. Yuk catat pengalaman parkirnya di *JukirHub*: jukir membantu
atau tidak, bayar berapa, ada karcis atau tidak.

👉 https://jukirhub.site/peta

Buka → ketuk tempatnya di peta → jawab singkat → kirim. Gratis, tanpa daftar.
Makin banyak yang lapor, makin jelas mana tempat yang jukirnya membantu dan mana yang sering tanpa karcis.

Catatan: cukup laporkan, tidak usah berdebat dengan jukir di lokasi 🙏
```

## 3. Pemilik usaha (cafe, toko, warung) yang parkirnya gratis

```
Halo [nama pemilik usaha] 👋

Kalau parkir di tempat Anda gratis / tidak ada jukir, pengunjung bisa tahu lewat *JukirHub*:
👉 https://jukirhub.site/peta

1. Saat di tempat Anda, buka tautan dan izinkan lokasi
2. Cari nama usaha Anda. Belum ada di peta? Tekan *Laporkan di lokasi saya*
3. Pilih *Tidak ada jukir*, lalu kirim

Ada poster "Parkir di sini gratis, tanpa jukir" dengan QR untuk ditempel di kasir / dekat parkiran. Bisa saya kirimkan.
```

## 4. Jawaban pertanyaan umum

- **Ini dari pemerintah?** Bukan. Laporan warga, belum diverifikasi pihak berwenang.
- **Nama saya kelihatan?** Tidak. Tanpa akun, tanpa nama. Lokasi hanya untuk memastikan Anda di tempat, dihapus
  setelah 7 hari.
- **Bisa melapor dari rumah?** Tidak. Laporan hanya bisa dari dekat tempatnya (±250 m) supaya tidak ada laporan palsu.
- **Kenapa warna tempat masih abu-abu?** Indikasi pungli baru tampil setelah ada minimal 3 laporan dari 2 orang.
- **Tempat saya salah nama / tidak pantas?** Kabari pengelola; tempat bisa disembunyikan.
